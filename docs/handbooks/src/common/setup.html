1 · Get set up — by Tuesday 15 September, 10 pm

Gate 1 is the first check of the sprint: all four of us have cloned the repository, verified our git identity, and pushed a first commit. Everything after it depends on this.

The repository is not a shared folder. Sohan's copy lives on Sohan's laptop. You make your own complete copy on your laptop by cloning it from GitHub, then you work, commit and push from there. GitHub is only the meeting point. Every command in this handbook runs on your own machine. (If you already have a working clone, start at step 4.)

Step 1 — Install the tools

  • Git. On Windows this also installs Git Bash — run every command in this handbook there, not in PowerShell or Command Prompt.
  • JDK 21 (Adoptium Temurin). Check that java -version and javac -version both report 21.
  • WSL2 with Ubuntu on Windows, because the experiments run on Linux. Inside Ubuntu install the JDK and Python too:
wsl --install -d Ubuntu
wsl -d Ubuntu
sudo apt update && sudo apt install -y openjdk-21-jdk make python3-pip
java -version

Step 2 — Clone onto your laptop

git clone https://github.com/sohan1611/rdt-udp.git
cd rdt-udp

You now have your own rdt-udp folder. Everything from here on happens inside it.

Step 3 — Tell git who you are, inside that folder

git config user.name  "{{NAME}}"
git config user.email "the-email-on-your-github-account"
This email decides whether you count as a contributor. It must be one of the addresses listed at github.com/settings/emails for your account {{GH}}. If you would rather not use a personal address, that page shows a private one ending in @users.noreply.github.com that links just as well. Commits with an unrecognised email show a grey avatar and are credited to nobody — and sir treats commit history as evidence of individual contribution.

Step 4 — Confirm the build

./build.sh

Every suite must report 0 failed — 54 tests across four suites as of 16 September. If anything fails, paste the output in the group chat the same evening.

Step 5 — Push your first commit

Open AI-USE.md and replace _[name]_ beside your role heading with your name. Then:

git checkout -b setup/{{FIRST_LOWER}}
git add AI-USE.md
git commit -m "Add {{FIRST}} to AI-USE.md"
git push -u origin setup/{{FIRST_LOWER}}
git log -1 --format='%an <%ae>'

The last command must print your own name and your GitHub email. Open the pull request on GitHub and ask {{PAIR_A}} to approve it. Your first push asks you to sign in to GitHub; on Windows a browser window opens, which is normal.

Done when: your PR is merged, git log shows your own name and email, and you can see yourself on the repository's Contributors page.
