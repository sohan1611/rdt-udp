6 · Team conventions — agreed on the Friday 18 call

Four people are writing code that has to plug together on Monday 21. Each item below is a decision that, left unspoken, becomes a day of integration bugs. On Friday 18 September at 8 pm, all four of us join a 30-minute call, confirm or change each default, and Shaili commits the result as docs/CONVENTIONS.md on Saturday morning. Until then, treat these as proposals — and if you disagree with one, bring the reason to the call rather than quietly doing something else.

#TopicProposed defaultOwner
1Protocol interfaceOne ArqProtocol interface with two operations: send a file to a peer and receive a file on a port. Both take a shared ProtocolConfig (window, RTO mode, sequence-space bits, payload size) and return RunStats. The session layer — metadata handshake, FIN teardown, hash check — sits outside the protocols and wraps whichever one is chosen, so Go-Back-N and Selective Repeat never reimplement it.Shaili
2Sequence numbersThe handshake is a DATA packet with seq = 0 and flag bit 0x01 (META) set. File data starts at seq = 1. The sequence space is k bits, set with --seqbits; the default is 32 and only wraparound tests make it small. Every comparison between sequence numbers uses modular arithmetic.Shaili
3What an ACK number meansThe ack field always holds a sequence number that was received. Stop-and-Wait and Selective Repeat acknowledge exactly that packet. Go-Back-N's ack n is cumulative: everything up to and including n arrived in order — the textbook convention. Each protocol restates its rule in its class comment.Shaili, Sinjan, Sohini
4Payload size1400 bytes per DATA packet; the last one is shorter. An 8 MiB file is therefore 5,992 data packets plus the handshake.Shaili
5Command-line flagsSender: --file --to host:port --protocol stopwait|gbn|sr --window N --rto adaptive|fixed:X --seqbits k --verbose.
Receiver: --port --out --protocol --window N --seqbits k --verbose. An unknown flag is an error, never silently ignored.		Shaili
6PortsFor manual runs the emulator listens on 9000 and the receiver on 9001. The experiment harness picks fresh ports for every run.Sohan
7Fixed RTO--rto fixed:1.5 means RTO = 1.5 × base RTT, where base RTT = emulator delay up + delay down. With --both delay=20 that is 40 ms, so fixed:1.5 is 60 ms.Sinjan
8Result lineAt the end of a transfer the sender prints exactly one line beginning RESULT  followed by a single JSON object of RunStats fields. Nothing else may print a line starting with RESULT. run_matrix.py reads only that line.Sohan
9What goodput meansGoodput = file bytes × 8 ÷ elapsed seconds, where elapsed runs from sending seq 1 to receiving the ACK that covers the last data packet — handshake and FIN excluded. Wire throughput = every byte the sender put on the wire, headers and retransmissions included, × 8 ÷ the same elapsed time.Sohan
10RunStats fieldsprotocol, window, seqbits, rto_mode, file_bytes, elapsed_ms, goodput_bps, wire_bytes, throughput_bps, data_sent, retransmissions, timeouts, dup_acks, acks_received, corrupt_dropped, sha256_match. The harness adds the run settings itself — seed, loss, dup, corrupt, reorder, delay, jitter.Sohan
11Trace linesus, dir, type, seq, ack, action, delayMs. The type and ack fields are new in the emulator rewrite. Today every ACK is logged with seq 0, so ACKs cannot be told apart — and Experiment 4 needs to tell them apart.Sohan
12LoggingNo printing per packet unless --verbose is given. Writing a line for every packet costs more than the protocol itself and makes goodput numbers meaningless.Everyone
13Tests and mainEvery new test class is added to both build.sh and the TESTS line of the Makefile, or it never runs. Run ./build.sh before every push: main must always build, because a compile error there stops all four of us.Everyone
14Sequence arithmeticOne small SeqSpace helper for every modular comparison — distance from the window base, "inside the window", "inside the previous window" — built on Math.floorMod and shared by Go-Back-N and Selective Repeat. The wraparound rule is then written once and tested once.Sohini
